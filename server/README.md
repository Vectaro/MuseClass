# server/

Сюди йде вміст `museclass-server.zip` (проєкт Maven, пакет `ua.museclass`) —
останню версію має закинути чат про сервер або чат про малину, окремим
комітом. Без `target/` і без `.env`.

Після цього цей файл замінюється справжнім README сервера з опису API й запуску.
Стан ділянки — [`docs/stan/server.md`](../docs/stan/server.md).
