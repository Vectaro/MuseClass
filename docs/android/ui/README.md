# UI Android поруч з прототипом (2026-10-08)

Ліворуч — `prototype/index.html` у вікні 400 px (Edge, `puppeteer-core`), праворуч — застосунок в
емуляторі `Pixel_9` (API 37, 411 dp) проти dev-сервера. Стан підігнано однаково, де це можливо:
інструмент «Фортепіано», клас «Dev: оркестр» (у прототипі — «Фортепіано, 3 клас»), фільтр «Народна».
Дані різні: у прототипі вигадані партитури (PDF, MIDI, лічильники), в Android — dev-сервер.

## Відмінності, які лишаю свідомо

1. **Шрифти.** В Instrument Sans і Instrument Serif немає кирилиці. У прототипі в браузері українські
   літери малює запасний шрифт зі стеку CSS (на ПК — Segoe UI / Georgia), Instrument видно лише в
   латиниці («MuseClass», «MusicXML»). В Android так само: кирилиця — системним шрифтом (Roboto і, для
   заголовків, системний serif). Вага 600/500 задана й для запасного шрифту (API 28+).
2. **Вхід поштою замість Google**: «Увійти з поштою» і «Створити акаунт з поштою» — діалоги нашого API.
   Примітку «Прототип. Реєстрація не справжня» прибрано. Пароль — щонайменше 8 символів (вимога сервера;
   у прототипі 6). Після входу в наявний акаунт онбординг пропускається.
3. **Код класу**: підказка «Спробуй PNO-3A або SOL-2B» → «Питай у викладача.» — демо-кодів немає.
4. **Перший клас**: код генерує сервер, тож рамка показує його після «Створити клас», а кнопка стає «Далі».
5. **Головна**: немає чипа «Ансамбль» (такого жанру на сервері немає). «Популярне зараз» — у порядку
   каталогу: відтворень сервер не рахує. Бейджі форматів — завжди «Інтерактив · MusicXML» (сервер
   зберігає лише MusicXML; MIDI і PDF прототипу — вигадані).
6. **Значки табів** — вектори тих самих символів ♪ 𝄃𝄃 ◍: системні гліфи цих символів різного розміру.
7. **Профіль**: 24 інструменти зі спільного довідника (у прототипі 11; сервер уже на довіднику).
   «Пройти онбординг заново» → «Вийти». Фото — лише на пристрої (сервер фото не зберігає).
8. **Переглядач**: системи переносяться за шириною екрана (рішення 2026-10-06), тож ноти крупніші й
   тактів у рядку менше. Режим «Партитура» — тост-заглушка: рендер кількох станів разом заморожено.
   Звуку немає: ▶ і ◷ — кнопки без звуку. ⤓, ✎, «+ партія», витягання партій — тости-заглушки.
   PDF-партитур не буває (на сервері лише MusicXML).
9. **Системні смуги** (годинник, жест «додому») — є в Android, у браузерному прототипі їх немає.
10. **Тост після вступу в клас з профілю** показується вже в бібліотеці — туди переходимо, як і прототип.

## Що не перевірено знімками
- Вибір фото (системний вибирач) — перевірено вручну лише кнопки; сам вибір фото в емуляторі не знімався.
- API нижче 37: емулятор один (API 37); вага шрифту для кирилиці до API 28 — просто «жирний».
