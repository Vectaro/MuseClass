# Рендер нот на Android — перший робочий екран (2026-10-07)

Емулятор `Pixel_9` (API 37, 1080×2424, 420 dpi), dev-сервер, учень
`student@dev.museclass`. Шлях: бібліотека → партитура → тап по партії.
Знімки зменшено вдвічі. Міжлінійний проміжок — 1,4 мм.

Що малюється: ключі (скрипковий, басовий, ударні; альтовий є, у демо не
трапився), ключові знаки, розмір на першій системі й зміна посеред, ноти й
акорди, крапки, додаткові лінійки, знаки альтерації з пам'яттю в такті,
штилі, прапорці, **в'язки** (вісімки, шістнадцяті), паузи, другий голос
(штилі вниз), форшлаги, артикуляція (акцент, стакато, тенуто, марcато),
репризи, тактові риски, кінцева риска, номери тактів. Перенос — **за
шириною екрана**, рядки розтягнуті на всю ширину, короткий останній — ні.

Ще не малюється (наступні кроки): ліги й ліги тривалості, тріолі (дужка з
цифрою), вольти, написи й ремарки (Andante, A/B/C), динаміка й вилки, текст
пісні, фермата, багатотактові паузи (у прототипі стискання увімкнене за
замовчуванням — тут два такти цілих пауз у альт-саксофона стоять окремо).

- **Темна тема**: аркуш лишається «папером» (`#FAF8F3`, як у прототипі),

- **Інверсія** — налаштування `sheet_inverted` (SharedPreferences
  `settings`); перемикача в інтерфейсі ще немає, знімок зроблено, виставивши
  його вручну.
