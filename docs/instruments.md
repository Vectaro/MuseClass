# Інструменти

Єдиний довідник — [`shared/instruments.json`](../shared/instruments.json).
Сервер, прототип і Android беруть список звідти, а не тримають свій. Новий
інструмент додається тільки туди, далі кожна ділянка підтягує зміну.

24 інструменти, згруповані за родинами. Порядок у файлі — порядок у UI.

| Родина | Інструменти |
|--------|-------------|
| клавішні | фортепіано, баян / акордеон |
| щипкові | гітара, бас-гітара, укулеле, бандура |
| смичкові | скрипка, альт, віолончель, контрабас |
| дерев'яні духові | флейта, блок-флейта, сопілка, гобой, кларнет in B♭, фагот, альт-саксофон in E♭, тенор-саксофон in B♭ |
| мідні | труба in B♭, валторна in F, тромбон, туба |
| ударні | ударні |
| голос | вокал |

Чому саме ці: усе, що реально трапляється в музичній школі та шкільному або
аматорському бенді в Україні. Блок-флейта і сопілка — масові шкільні,
бандура і баян — наші народні. Оркестрові рідкісні (арфа, челеста,
пікколо, саксофони сопрано/баритон) свідомо не додані: партія з ними
отримує найближчий код або `null`, а інструмент — лише м'який сигнал
ранжування, тож нічого не ламається.

## Поля
- `code` — стабільний ідентифікатор для API і БД. Не перейменовувати; якщо
  довелось — запис у `renamed` і міграція.
- `name` — українська назва в UI. Строй у назві лишається там, де його
  пишуть у партіях (труба in B♭).
- `family` — для групування в UI.
- `clef` — звичний ключ партії: `treble`, `bass`, `alto`, `perc`,
  `treble+bass` (два стани).
- `transpose` — на скільки півтонів звучання відрізняється від написаного
  (від'ємне — звучить нижче). Гітара й контрабас −12 (пишуться октавою
  вище), блок-флейта (сопрано) +12. У прототипі поле `ts` має протилежний
  знак: `ts = -transpose`.
- `gm` — номери програм General MIDI (з 1, як у MusicXML) для впізнавання
  партії без назви і для SoundFont на Android. Програма належить лише одному
  інструменту.
- `synth` — тембр синтезу прототипу (piano, guitar, bandura, bass, violin,
  trumpet, trombone, sax, flute, voice). На Android замість нього — `gm`.
- `keywords` — підрядки для впізнавання за назвою партії, в нижньому
  регістрі.

## Впізнавання партії
1. Назва партії й інструмента в нижньому регістрі; інструменти
   перебираються в порядку `detect_order`, перший, чий keyword входить у
   назву, перемагає. Порядок важливий: бас-гітара раніше за гітару, фагот
   (contrabassoon) раніше за контрабас, саксофони раніше за альт і вокал
   (tenor), гобой (english horn) раніше за валторну (horn).
2. Якщо назва не допомогла: MIDI-канал 10 → `drums`, далі програма з `gm`.
3. «Sax»/«саксофон» без уточнення → `saxophone_alto` (`fallback`).

Відома двозначність: «Альт» / «Альти» у хоровій партитурі — голос, а не
інструмент, але за назвою це не відрізнити, тож береться `viola`. «Alto
voice» і «Contralto» дають `voice`. Якщо заважатиме — правило з контекстом
(решта партій — голоси → `voice`).
