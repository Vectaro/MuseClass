# MuseClass — стан проєкту

Стан розбитий на файли за ділянками, щоб паралельні чати не затирали одне
одного. Правила роботи — у [`CLAUDE.md`](../../CLAUDE.md) в корені.

| Файл | Що в ньому |
|------|------------|
| [`open.md`](open.md) | усе, що чекає дії або рішення — **читати першим** |
| [`decisions.md`](decisions.md) | ухвалені рішення: продукт, формат, нотація, звук, доступи |
| [`prototype.md`](prototype.md) | веб-прототип: що працює, чого немає, як перевіряється, граблі |
| [`server.md`](server.md) | museclass-server: API, перевірки |
| [`hardware.md`](hardware.md) | де живе сервер: ПК, малина, NUC, деплой |
| [`android.md`](android.md) | як переносити на Android |

## Що це
Android-застосунок на Java (Android 7+, API 24). Обмінник нотами: викладач
роздає бібліотеку класу, учні читають і грають. Наголос на кавери, на
можливість набирати власні ноти прямо в застосунку і на витягання партії
потрібного інструмента з партитури.
