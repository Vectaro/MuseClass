# Відкрите

Єдиний список того, що чекає дії або рішення. Закрите — прибирати звідси і
переносити результат у файл ділянки.

## Зробити (за пріоритетом)
1. **Купити залізо під сервер** — малину або NUC, див. «Вирішити» і
   [`hardware.md`](hardware.md).

## Вирішити (Влад)
- **Хто витягує партії для сервера.** Зараз сервер віддає цілий файл
  партитури. Або `GET /scores/{id}/parts/{n}` з витяганням на сервері, або
  лишити витягання клієнтові.
- **NUC на J3455 за ~2000 грн — купувати чи ні.** Поки лише знайдене
  оголошення (8 ГБ RAM, SSD 256 ГБ). Якщо купується — малина з плану
  випадає, NUC стає постійним домом. Див. [`hardware.md`](hardware.md).

- **Інструменти: перейти на спільний довідник** `shared/instruments.json`
  (24 інструменти, опис — [`docs/instruments.md`](../instruments.md)).
  Сервер — зроблено 2026-10-07 (див. [`server.md`](server.md)), Android —
  2026-10-08 (список і назви з `assets/instruments.json`, тобто з
  `shared/`). Лишився прототип: список, назви й строї звідти; старий код
  `saxophone` сервер тепер відкидає (400).

## Запропоновано, не зроблено
- Довідник інструментів, знайдено на файлах OSMD: «Acoustic Bass Drum»
  (назва інструмента в партії ударних) впізнається як `bass_guitar` — keyword
  `acoustic bass` бас-гітари. Варіант: `drums` у `detect_order` раніше за
  `bass_guitar` або keyword `bass drum` в ударних з таким самим пріоритетом.
- Довідник: слова для «sax без уточнення» (`sax`, `сакс`) зараз зашиті в
  серверному детекторі; можна винести в `fallback`, щоб прототип і Android
  брали їх звідти ж.
- Сервер: перерозпізнати інструменти партій уже завантажених партитур після
  зміни довідника (міграція V2 лише перейменувала саксофони; решта старих
  `null` лишилась). На бойовій партитур поки, схоже, немає; на dev це робить
  seed.
- Перемикач `TEST_DB_URL` в `ApiFlowTest`, щоб тест міг брати готовий Postgres
  замість контейнера.
- Розгортання D.C. / D.S. при відтворенні (реприза з вольтами вже грається).
- Третій і далі голоси в такті; зараз модель знає два.
- **Прототип (`engine.js`), знайдено при перенесенні рендера на Android:**
  - лінії стану починаються після ключа (`padL-8`), ключ висить зліва від
    них; на Android лінії йдуть від лівого краю під ключем;
  - знаки альтерації в тактах після зміни тональності рахуються від
    початкової (`keyAlters(fifths)` у першому проході бере `opts.fifths`,
    зміна застосовується лише в останньому проході); на Android — від тієї,
    що діє в такті. На демо не проявляється.
- Android, рендер (заморожено 2026-10-08), наступні кроки за порядком: ліги й
  ліги тривалості, тріолі, багатотактові паузи, вольти/написи/динаміка/вилки,
  текст пісні, фермата, режим «Партитура» (кілька станів разом); далі щипок
  для масштабу й курсор плеєра.
- Android, UI за прототипом — заглушки, що чекають справжньої роботи:
  звук плеєра (▶, метроном, стрій, репризи, rit.), редактор, імпорт файлу
  (`POST /scores` уже є), експорт / витягання партій, олівець, «+ партія»,
  «Видати ноти класу». Див. [`android.md`](android.md), «UI за прототипом».
- Сервер, щоб Android став ближчим до прототипу: жанр «Ансамбль» (у каталозі
  немає — чип прибрано), лічильник відтворень для «Популярне зараз», фото
  профілю (зараз лише на пристрої).
