# MuseClass

Android-застосунок на Java (Android 7+, API 24) — обмінник нотами. Викладач
роздає бібліотеку класу, учні читають і грають. Наголос на кавери, набір
власних нот прямо в застосунку і витягання партії потрібного інструмента з
партитури.

## Структура

```
prototype/   інтерактивний веб-прототип (один HTML) і його тести
server/      museclass-server: Spring Boot 4.1, Java 21, PostgreSQL 16, Docker Compose
android/     Android-клієнт (ще не почато)
docs/stan/   стан проєкту: відкрите, рішення, ділянки
CLAUDE.md    правила для чатів Claude, що працюють з репо
```

Звідки почати: [`docs/stan/README.md`](docs/stan/README.md), а що зараз
чекає дії — [`docs/stan/open.md`](docs/stan/open.md).
