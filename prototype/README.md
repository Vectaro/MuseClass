# prototype/

Веб-прототип MuseClass: один самодостатній HTML-файл без залежностей.
Онлайн — артефакт https://claude.ai/artifact/QrwX2jX9GHz6VV9dvLL4hM
(оновлювати **за цим URL**, не публікувати новий).

Джерело правди — файли в цій теці. `index.html` — їхня збірка: спершу коміт,
потім публікація того самого файлу в артефакт.

## Склад
| Шлях | Що це |
|------|-------|
| `index.html` | зібраний прототип — те, що відкривається і публікується |
| `engine.js` | нотний рушій: верстка стану, вʼязки, ліги, тріолі, партитура |
| `clef.js` | генератор контуру скрипкового ключа з кривих Безьє |
| `tools/` | збирач сторінки і малювання нот у SVG для огляду оком |
| `tests/` | клік-тести на jsdom і перевірка довжини тактів |
| `audio/` | вимірювання й підгонка тембрів |

## Збірка
`index.html` містить три згенеровані шматки: рушій, таблицю голосів і шлях
ключа. Після правки частин:

    python3 tools/build.py

Напрямок один — від частин до сторінки. Руками в `index.html` правиться лише
те, чого немає в частинах (екрани, стан, плеєр).

> Чому так. Тричі траплялось: правиш `engine.js`, вставляєш у сторінку цілим
> блоком — і точкова правка, зроблена в сторінці раніше, зникає без сліду.
> `tools/build.py --check` тепер входить у набір тестів і не дає зібраному
> файлу розійтися з частинами непомітно.

## Перевірки

    npm install        # потрібен jsdom
    npm test           # збірка + три набори тестів

- `tests/smoke2.js` — онбординг, імʼя і фото, теми, панель плеєра, партитура
  бенду й режим партії, стиснення пауз, ударні, витягання партій з перевіркою
  вмісту архіву, редактор, биті файли, round-trip.
- `tests/smoke3.js` — підсвітка в часі (годинник AudioContext і
  requestAnimationFrame підмінені, перевіряється яка саме нота світиться в
  кожен момент), акорди, тацети, звук, реєстрація поштою, кілька класів,
  вступ за кодом, нотація, нотація у звуці, круговий прогін через MusicXML.
- `tests/check.js` — довжина кожного такту з урахуванням зміни розміру,
  відсутність випадкових знаків у транспонованих партіях.

Тільки синтаксису не досить: один раз уже був зламаний переглядач, який
перевірку синтаксису пройшов. Тому тести перевіряють поведінку, а картинки з
`tools/` дивляться оком.

Стан ділянки — [`docs/stan/prototype.md`](../docs/stan/prototype.md).
