# tools/

| Файл | Що робить |
|------|-----------|
| `build.py` | збирає `index.html` із частин; `--check` лише звіряє |
| `dump-etude.js` | малює демо-етюд у `etude.svg` — усю нотацію видно разом |
| `dump-score.js` | малює партитуру бенду у `score.svg` |
| `dump-band.js` | малює окремі партії бенду |

Рендер у картинку — не прикраса, а спосіб перевірки. Оком знайшлись
перевернуті паузи, такти на пʼять доль, порожні квадратики замість ключів,
зайві дієзи в транспонованій партії, тріолі, що стали шістнадцятими, назви
партій поверх ключів і стани, що налазили один на одного. Жоден клік-тест
цього не бачив.

SVG → PNG, якщо треба подивитись:

    python3 -c "import cairosvg;cairosvg.svg2png(url='etude.svg',write_to='etude.png',scale=2)"
